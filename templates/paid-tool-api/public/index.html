Two-phase app API

  
Sign in at /__semesh/login. First POST the input to /api/tool/quote with
    one stable Idempotency-Key. Persist the returned prepared bundle. Then POST
    that unchanged bundle and the same key to /api/tool/invoke. Retry that POST only
    while no Invocation ID is known; afterward /api/tool/observe performs canonical GET-only recovery.
